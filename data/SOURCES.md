# Sources

## Real data (public)

| Data | Source | Access | Terms / notes |
|---|---|---|---|
| Daily close of BTC, ETH, LTC, TRX, BNB, SOL, USDC vs USDT, 2024-11-01 to 2026-10-31 | Binance public market-data API, `GET https://data-api.binance.vision/api/v3/klines` (interval `1d`) | Free, no API key | Public market data endpoint. 1 USDT is treated as 1 USD (USDT itself is set to 1.00). |
| EUR/USD reference rate (daily, business days) | European Central Bank Data Portal, series `EXR.D.USD.EUR.SP00.A`, `https://data-api.ecb.europa.eu/service/data/EXR/D.USD.EUR.SP00.A` | Free, no API key | ECB statistics may be reused with source acknowledgement. Weekends and holidays use the last published rate. |

- Frozen file: `data/raw/prices/prices_daily.csv` (8 currencies x 730 days).
- Download date: see `data/raw/prices/DOWNLOADED_ON.txt` (2026-11-10). Re-run `python src/fetch_prices.py` to refresh.
- `price_eur = price_usd / ECB EUR-USD rate`.
- Why not CoinGecko: since 2025, the free public API only serves the last 365 days, and the study needs 24 months.

## Simulated data

Everything in `data/clean/` is generated by `src/generate_sim.py` (seed 42). It is **not** Coinspaid data and not data of any real merchant. See `ASSUMPTIONS.md`.
